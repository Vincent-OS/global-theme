# Vincent OS Global Theme
This is the default KDE Plasma global theme for Vincent OS.

## Installation
The global theme is installed by default on Vincent OS. The source files are located in:
```
/usr/share/plasma/look-and-feel/
```

### Easy method
You can install the Vincent OS by going on ``System -> System Settings``.

The following settings to locate is on ``Color & Themes -> Global Theme -> Get New...``. Simply searching "Vincent OS" and install it!

### Manual extract
1. Download the latest [release](https://github.com/Vincent-OS/global-theme/releases) (file in format ``.tar.xz``).
2. Extract the file on the following path: ``$HOME/.local/share/plasma/look-and-feel`` (if the folder ``look-and-feel`` doesn't exist, create it first)
3. Open ``System -> System Settings``.
4. Go to ``Color & Themes -> Global Theme -> Get New...``.
5. Now you can select it!

# Contribute to Vincent OS Global Theme
Vincent OS Global Theme is open to all contributions! You just need to respect the code of conduct.

## How to contribute?
You can contribute to Vincent OS Global Theme several ways:
- Theme
- Translation

### Theme
What you need to contribute to Vincent OS Global Theme:
1. Latest version of Vincent OS
2. File Editor (kate, Visual Studio Code...)
3. (Optional) ``plasma-sdk`` package installed on your system.

To contribute:
1. Fork this repository
2. On your forked repository, create a new branch for developping your work.
3. Do modification.
4. Always test your modification.
5. If all goods, send a Pull Request to your master branch on your forked repository.
6. Send a Pull Request to this repository and follow instructions.
